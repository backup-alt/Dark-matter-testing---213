Overview

Four ways to access models

OpenCode is free, open-source (MIT) software. How you pay for models depends on the route you choose.

Free Models Limited time

$0 — no sign-in needed
  • Built into the OpenCode app (CLI, desktop, IDE)
  • Unpublished daily request limits
  • OpenCode-only — free chat models require OpenCode
  • Hide with OPENCODE_DISABLE_FREE_MODELS=1

OpenCode Go Subscription

$10/mo · Go Plus $40/mo · Teams $20/member
  • Curated open-weight lineup with per-model allowances
  • Works in OpenCode, Claude Code, Codex & Pi
  • Top up credit if you run out, cancel any time

Console Pay-as-you-go Per token

$20 min top-up + ~4.6% + $0.31 fee
  • Largest catalog — frontier & open-weight models
  • Billed per token from prepaid credit, at cost
  • Budgets, auto-recharge, zero retention by default

Accessible · any plan

Bring your own access

Beyond the OpenCode catalog, OpenCode connects to anything you already have — no OpenCode model fees.

🔑 API keys

Plug in any provider key — Anthropic, OpenAI, Google, xAI, Mistral, Groq, local Ollama / LM Studio / vLLM — and pay that provider's normal API rates.

💬 ChatGPT Plus / Pro

Log in with an existing ChatGPT Plus or Pro subscription to use OpenAI models with that plan's limits and billing.

🟣 Claude Pro / Max

Use a Claude Pro or Max subscription. Since v2.2.3 OpenCode also ships a built-in Claude Agent provider that runs on your Claude Code login.

🐙 GitHub Copilot

Authenticate with your existing GitHub Copilot subscription and access Copilot-enabled models inside OpenCode.

🏠 Local models

Run Ollama, LM Studio or vLLM locally — $0 plus your own hardware, fully private, no rate limits beyond your GPU.

🏢 Teams & Enterprise

Workspace owners can connect their own providers for the whole team, with budgets, policies, SSO and per-member spend caps.
